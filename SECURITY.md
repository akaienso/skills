# Security

## Reporting

Report a vulnerability or a leaked secret privately: on GitHub, open the repository's
**Security** tab and choose **Report a vulnerability**. Please don't open a public issue.

## What counts

- A secret, token, key or password committed anywhere in the history
- Client, project or personal details that shouldn't be public
- A script in this repository that could change or delete files it shouldn't
- A skill that tells an agent to do something unsafe

## Response

Exposed secrets are rotated first, then removed from the repository. You'll get a reply once the
report has been looked at.
